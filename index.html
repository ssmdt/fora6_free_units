และการรับค่าคอมมิชชั่น
แนวทางปฏิบัติสำหรับการแจกเครื่องตรวจน้ำตาล/ยูริก/ไขมัน พร้อมระบบอ้างอิงเพื่อรับค่าคอมมิชชั่นจากยอดซื้อครั้งแรกของลูกค้า
1

คัดเลือกลูกค้าเป้าหมาย

มองหาลูกค้าที่มีแนวโน้มสนใจดูแลสุขภาพ เช่น กลุ่มเสี่ยงเบาหวาน เสี่ยงโรคเกาท์ หรือไขมันในเลือดสูง ที่น่าจะได้ประโยชน์จากการมีเครื่องตรวจไว้ใช้เองที่บ้าน

2

แอดไลน์ @foracare แจ้งข้อมูลกับแอดมิน

สแกนเพื่อแอดไลน์ @foracare

แอดไลน์ @foracare แล้วแจ้งชื่อสกุลพนักงาน หน่วยงานที่สังกัด และจำนวนเครื่อง FORA 6 ที่ต้องการแจกให้กับลูกค้าเป้าหมาย เช่น "สมหญิง จริงใจ ฝ่ายบุคคล จำนวน 3 เครื่อง" จากนั้นแอดมินจะนัดหมายเพื่อรับเครื่องต่อไป

3

แจกเครื่อง FORA 6 Connect ฟรี

มอบเครื่องตรวจ FORA 6 Connect ให้ลูกค้าโดยไม่มีค่าใช้จ่าย พร้อมแนบแถบทดสอบตัวอย่าง (Blood Glucose / Uric Acid / Total Cholesterol) จำนวนเล็กน้อยให้ลองใช้งานจริง

ไม่มีค่าใช้จ่ายสำหรับลูกค้า
4

แจ้ง Reference Code ให้ลูกค้าเก็บไว้

แจ้งรหัสอ้างอิง (Reference Code) รูปแบบ Fora6_XXXX ให้ลูกค้าจดหรือเก็บไว้ เพื่อใช้แจ้งตอนสั่งซื้อแถบตรวจเพิ่มในอนาคต

5

ลูกค้าแอดไลน์สั่งซื้อแถบตรวจเพิ่ม

ลูกค้าแอดไลน์ทางการ @foracare และแจ้ง Reference Code เช่น Fora6_XXXX พร้อมแจ้งรายการแถบตรวจที่ต้องการสั่งซื้อ

6

ลูกค้าได้รับส่วนลดทันที

คำสั่งซื้อแรกที่แจ้ง Reference Code จะได้รับส่วนลด 100 บาท เมื่อมียอดซื้อขั้นต่ำ 500 บาทขึ้นไป

7

พนักงานรับค่าคอมมิชชั่นอัตโนมัติ

ระบบตรวจสอบ Reference Code จากคำสั่งซื้อแรกของลูกค้า และคำนวณค่าคอมมิชชั่นให้พนักงานเจ้าของรหัสโดยอัตโนมัติ เมื่อสิ้นสุดจัดรายการ โดยแอดมินจะทัก เพื่อขอเลขที่บัญชี ในการโอนเงินค่าคอมมิชชั่น (ระยะเวลาภายใน 2 สัปดาห์ หลังหมดโปรโมชั่น 31 ตุลาคม 2026)
